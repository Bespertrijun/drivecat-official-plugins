连接与网盘

填写 DriveCat 能访问的地址。Docker 中的 localhost 指向 DriveCat 容器。

高级设置

持续上传时，每批最多合并等待 60 秒；网络异常最多自动重试 3 次。首次启用仅处理之后完成的上传。

测试扫描

使用已保存的设置，实际向 OneStrm 提交一次扫描。通知成功只代表 HTTP 已接收；STRM 生成请在 OneStrm 确认。
